# DNT Professional Discussion Prep (test site)

A static website to help DNT dental nursing learners prepare for their Professional Discussions.

- `index.html`: the guide
- `practice.html`: timed practice scenarios with follow-up questions and self-check checklists
- `knowledge.html`: knowledge test across Units 1 to 10 (practice by unit or a timed 65-question, 90-minute mock with a revision report)
- `assets/questions.js`: the question bank (multiple choice and extended multiple choice sets)
- `assessor.html`: AI assessor (under construction)
- `assets/scenarios.js`: all scenario content. Edit this file to add or change scenarios.

Scope: only the ACs DNT assesses by Professional Discussion (KE 1.1.9, PE 1.2.10, KE 7.1.2, 7.1.3, 7.1.4, 7.1.11, PE 7.2.1, 7.2.2, 7.2.3).

No build step. Open `index.html` in a browser, or host with GitHub Pages (Settings, Pages, deploy from branch).

Practice progress is saved in the learner's own browser only.
